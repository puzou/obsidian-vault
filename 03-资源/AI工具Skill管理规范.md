# AI 工具 Skill 管理规范

## 核心原则

**只装近期一定会用到的 skill，其余一律不装。按场景装，不按仓库逛。**

## 各工具 Skill 需求

### Claude Code

不需要额外 skill 和 MCP。自带的 Agent 能力够用，按需配 MCP（目前默认 filesystem 即可）。

### GeminiCLI

不需要额外 skill。WSL 下纯代码交互，默认能力够用。

### WorkBuddy

只需装以下内置 skill：

| Skill | 用途 |
|-------|------|
| pdf | 读 PDF 论文整理成笔记 |
| docx | 生成 Word 文档（作业/报告） |
| pptx | 生成 PPT（课堂展示） |
| xlsx | 处理表格数据（实验数据整理） |
| 浏览器自动化 | 抓网页资料 |

同类 skill 只留一个（如 pdf 和 pdfkit-py 选其一）。

### 连接器

已开：微信（手机端交互）

暂不开（按需再开）：腾讯文档（在线协作时）、QQ邮箱、TAPD、乐享、微云、问卷

用不到的连接器别开，会增加对话初始化开销。

## Skill 安装决策流程

```
遇到一个具体任务
  → 发现当前工具做不了/做不好
    → 搜有没有 skill 能解决
      → 有就装
      → 没有就换个工具做
```

不要去 skill 市场里"逛街"，按需安装。

## Skill 管理规则

1. **按场景装，不按仓库逛** — 先有任务，再找 skill
2. **同类只留一个** — 功能重叠的选用的人多、更新频繁、文档清楚的
3. **不确定就不装** — 看了描述不确定会不会用到 = 不会用到
4. **装了不用就卸** — 每月回顾，过去一个月没用过的直接卸
