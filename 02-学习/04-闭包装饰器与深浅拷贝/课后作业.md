### 选择题

### 编程题（参考实现）
**A.**
```python
def make_accumulator():
    count = 0
    def inner():
        nonlocal count
        count += 1
        return count
    return inner
```

**B.**
```python
def validate_positive(fn):
    def wrapper(n):
        if not isinstance(n, int) or n <= 0:
            print("⚠️ 参数必须是正整数！")
            return None
        return fn(n)
    return wrapper
```

**C.**
```python
import copy

data = {"users": [{"id": 1, "name": "Alice"}, {"id": 2, "name": "Bob"}]}

# 浅拷贝
shallow = copy.copy(data)
shallow["users"][0]["name"] = "Alice Smith"
# 原数据受影响！因为 users 列表中的字典是共享引用
print(data["users"][0]["name"])  # Alice Smith ← 被改了

# 深拷贝
deep = copy.deepcopy(data)
deep["users"][1]["id"] = 99
# 原数据不受影响
print(data["users"][1]["id"])  # 2 ← 没变
```

**解释**：浅拷贝只复制顶层，嵌套的 list/dict 仍是引用关系；深拷贝递归复制所有层级，完全独立。
