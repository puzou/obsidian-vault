## 练习一：闭包 — 制作一个计数器

### 目标
用闭包实现一个调用一次就 +1 的计数器。

### 引导

**Step 1**：先写出闭包的骨架 —— 外部函数 + 内部函数 + return

```python
def make_counter():
    count = 0          # 这是我们要"记住"的变量

    def inner():       # 内部函数要能访问并修改 count
        # TODO: 让 count 加 1，然后打印
        pass

    return inner       # 返回内部函数对象
```

**Step 2**：思考 —— 内部函数里怎么修改外部变量？

> 💡 提示：普通赋值 `count = count + 1` 会报错，因为 Python 默认把 `count` 当作局部变量了。

```python
def make_counter():
    count = 0

    def inner():
        # 在这里声明 nonlocal，然后修改
        pass

    return inner
```

**Step 3**：完成代码并测试多次调用

```python
counter = make_counter()
counter()   # 应该输出: 当前计数: 1
counter()   # 应该输出: 当前计数: 2
counter()   # 应该输出: 当前计数: 3
```

**Step 4（进阶）**：能不能让计数器从指定数字开始？比如从 100 开始？

> 💡 提示：给外部函数加个参数就行。

## 练习二：装饰器 — 给函数加计时器

### 目标
写一个装饰器，自动测量被装饰函数的执行时间。

### 引导

**Step 1**：回忆装饰器的四要素结构

```python
import time

def timer(fn_name):        # 接收原函数
    def inner(*args, **kwargs):
        # TODO: 记录开始时间
        # TODO: 调用原函数 fn_name(*args, **kwargs)
        # TODO: 记录结束时间
        # TODO: 打印耗时
        pass
    return inner
```

**Step 2**：用 `time.time()` 获取当前时间戳

```python
start = time.time()
# ... 执行一些操作 ...
end = time.time()
print(f"耗时: {end - start:.4f} 秒")
```

**Step 3**：完成装饰器并测试

```python
@timer
def slow_function():
    total = 0
    for i in range(10000000):
        total += i
    return total


@timer
def fast_function(name):
    print(f"Hello, {name}!")


slow_function()
fast_function("Python")
```

**预期输出类似**：
```
函数 slow_function 耗时: 0.XXXX 秒
Hello, Python!
函数 fast_function 耗时: 0.0000 秒
```

## 练习三：装饰器 — 带参数的日志装饰器

### 目标
写一个可以自定义日志级别的装饰器。

### 引导

**Step 1**：带参数装饰器需要三层嵌套，最外层接收参数

```python
def log(level="INFO"):            # 第一层：接收装饰器参数
    def decorator(fn):             # 第二层：接收原函数（真正的装饰器）
        def wrapper(*args, **kwargs):  # 第三层：实际执行的函数
            # 根据level打印不同格式
            if level == "DEBUG":
                print(f"[DEBUG] 正在调用 {fn.__name__}")
            elif level == "INFO":
                print(f"[INFO] 调用 {fn.__name__}")
            result = fn(*args, **kwargs)
            return result
        return wrapper
    return decorator
```

**Step 2**：测试不同的日志级别

```python
@log(level="DEBUG")
def add(a, b):
    return a + b

@log(level="INFO")
def greet(name):
    return f"Hi, {name}"


print(add(2, 3))
print(greet("Claw"))
```

## 练习五：综合挑战 — 用装饰器实现缓存

### 目标
写一个简单的缓存装饰器：如果同样的参数调用过，直接返回缓存结果，不再重新计算。（斐波那契数列是经典场景）

### 引导

```python
def cache(fn):
    cache_dict = {}              # 用字典存 {参数: 结果}

    def wrapper(n):
        if n in cache_dict:
            print(f"📦 缓存命中: fib({n}) = {cache_dict[n]}")
            return cache_dict[n]

        result = fn(n)           # 没有缓存才计算
        cache_dict[n] = result
        print(f"✅ 计算并存入缓存: fib({n}) = {result}")
        return result

    return wrapper


@cache
def fib(n):
    """递归求第 n 个斐波那契数"""
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)


# 测试
print("\n=== 第一次调用 ===")
print("fib(10) =", fib(10))

print("\n=== 第二次调用（应该全走缓存）===")
print("fib(10) =", fib(10))

print("\n=== 单独调用子问题 ===")
print("fib(5) =", fib(5))  # 这个在计算 fib(10) 时已经算过了
```

> 观察输出：第二次调用时有多少次"缓存命中"？这体现了缓存的威力。
