## 关键知识点清单

写代码时留意以下知识点，都是课程中讲过的：

| #   | 知识点                       | 在哪里用到                     |
| --- | ------------------------- | ------------------------- |
| 1   | `__init__` 初始化属性          | student.py、studentcms.py  |
| 2   | `__str__` 格式化输出           | student.py                |
| 3   | `__dict__` 对象转字典          | save_student              |
| 4   | `**dict` 字典解包             | load_student              |
| 5   | `for...else` 循环正常结束走 else | del / update / search_one |
| 6   | `@staticmethod` 静态方法      | show_view                 |
| 7   | `with open` 文件操作          | save / load               |
| 8   | `try...except` 异常处理       | load_student              |
| 9   | `eval()` 字符串转 Python 对象   | load_student              |
| 10  | `input()` 用户输入            | 各功能方法                     |
